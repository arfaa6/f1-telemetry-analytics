# 🏎️ F1 Telemetry Analytics Pipeline

A Python-based telemetry analysis tool designed to ingest, process, and visualize Formula 1 session data using the `FastF1` API, `Pandas`, and `Matplotlib`. 

This project allows users to extract driver telemetry—including speed profiles, throttle application, braking zones, and gear selections—to compare driver performance across qualifying and race sessions.

---

## 📌 Features

* **Session Data Retrieval:** Automated caching and fetching of F1 session timing and telemetry data.
* **Driver Telemetry Comparison:** Side-by-side speed trace and lap time analysis between drivers.
* **Data Visualization:** High-resolution plots illustrating telemetry metrics along track distance.
* **Modular Architecture:** Structured Python implementation utilizing Object-Oriented Programming (OOP) principles.

---

## 🛠️ Tech Stack & Dependencies

* **Language:** Python 3.12
* **Data Manipulation:** `pandas`, `numpy`
* **Telemetry Data Source:** `fastf1`
* **Visualization:** `matplotlib`
